# programmers_b2b

프로그래머스 B2B 기업교육 랜딩페이지 프로젝트입니다.

## 현재 구현

`중소기업 인재키움 프리미엄 훈련` 랜딩페이지 1차 프로토타입

- Next.js 15 + TypeScript
- 승인된 AI융합형 8개 과정만 반영
- 반응형 레이아웃
- 과정 성장 로드맵
- 지원 가능 여부 UI
- Why Programmers / 기업교육 사례 / 과정 추천
- 신청·환급 프로세스
- FAQ 아코디언
- Final CTA

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 확인합니다.

## 작업 브랜치

`feature/talent-premium-landing`

> 기업교육 실적 수치, 실제 기업 사례, 다운로드 파일, 상담 링크는 확정 데이터 수급 후 교체가 필요합니다.
